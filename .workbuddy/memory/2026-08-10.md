## 安全审查：http-raw-log / core 模块
对 core 模块做了静态安全审查（HttpRawLogFilter、HistoryApi、StatisticsApi、AutoWebConfig、RequestWrapper/ResponseWrapper/FormRequestWrapper、History、FileAppender、InMemoryAppender）。

主要风险：
- 高危：`/httpRawLog/history`、`/httpRawLog/statistics` 两个端点**无任何鉴权**；history 接口明文返回含 cookie/authorization/请求体/响应体的完整 HTTP 流量，生产环境开启等于内网抓包器，泄露凭据与 PII。
- 中危：Filter 默认记录全部 body/header，默认 headers 建议含 `cookie`，未做脱敏；history 内存队列常驻明文敏感数据。
- 低危/质量：FormRequestWrapper 反射 Tomcat 内部 `ApplicationPart.fileItem` 强耦合且循环内 clearCache；FileAppender 嵌套 O(n*m) 遍历、单线程扫大日志文件有资源滥用面；StatisticsApi.map 按 URL 无上限缓慢增长。
- 亮点：v0.9.15 已修复竞态、1MB OOM 限制、WeakReference 等问题，说明维护者关注稳定性。
- 用户关注范围限定为 core 模块（不含 redis-web-admin、log-record）。
- 【更正】用户确认本项目是 jar lib，鉴权/授权由使用方负责（如 Spring Security），故 history/statistics 端点的「未授权访问」不列为本项目漏洞，已从高危清单剔除。后续审查聚焦非鉴权类真实代码缺陷。
